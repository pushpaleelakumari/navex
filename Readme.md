# HTML/CSS Assessment

## Overview
This project is an implementation of the provided mockup (`CITestMockup.png`) using only HTML and CSS.
The goal was to match the layout and styles as closely as possible to the design specifications.

## Tech Used
- HTML5
- CSS3 (Flexbox for layout, responsive design)
- Google Fonts (Roboto, Barlow)

## Features
- Two-column layout: "Our Commitment" (left) and "To Make a Report" (right)
- Responsive design (columns stack on smaller screens)
- Navigation links styled with hover effects
- Buttons styled with transitions and hover state
- Header and footer background color applied per design specs

## How to Run
1. Open `index.html` in a browser.
2. Ensure `ciCLIENT.css` is in the same folder.

## Notes
- Links containing `_CLIENTID_` are placeholders and will be replaced in production.
- The project is static and for assessment/demo purposes only.
